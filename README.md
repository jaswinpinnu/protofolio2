## Preview locally
1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Extract the ZIP and open this folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html` → **Open with Live Server**.
5. Keep an internet connection on for Three.js and Google Fonts loaded from CDNs.

## Publish with GitHub Pages
1. Create a repository on [GitHub](https://github.com/).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is not nested inside another folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then click **Save**.
6. Wait a few minutes for GitHub Pages to publish.

Typical project-site URL: `https://yourusername.github.io/repository-name/`.
